# OTT Subscriber & Revenue Dashboard

A Power BI dashboard that analyzes OTT subscriber performance, revenue, subscription plans, regional performance, and customer churn.

## Dashboard pages

### 1. Dashboard Overview

- Active subscribers
- Total revenue
- Average churn rate
- Net new subscribers
- Subscriber and revenue trend
- Revenue by region
- Interactive filters for year, plan type, and region

### 2. Churn Analysis

- Monthly churn rate
- New subscribers versus churned subscribers
- Total churned subscribers and total new subscribers
- Regional retention summary
- Recommended retention action

## Key insights

- Asia Pacific is the highest revenue-generating region.
- Subscriber and revenue trends decline over the selected period.
- Average churn remains close to 3%.
- Churned subscribers exceed new subscribers, resulting in negative net subscriber growth.
- Targeted retention offers can help improve subscriber growth.

## Tools used

- Microsoft Power BI Desktop
- DAX measures
- Interactive slicers and page navigation buttons

## How to use

1. Download the `.pbix` file.
2. Open it in Microsoft Power BI Desktop.
3. Use the Year, Plan Type, and Region slicers to explore results.
4. Use the navigation buttons to move between Dashboard Overview and Churn Analysis.

## Data period

January 2023 to December 2024
